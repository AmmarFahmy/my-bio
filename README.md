# Profile Bio Site

A modern, mobile-first bio link page built with **Next.js 14 (App Router)** and **Tailwind CSS**. Swap in your own avatar, text and links in minutes.

## Getting Started

1. Install dependencies:

```bash
pnpm install # or npm install / yarn
```

2. Run the development server:

```bash
npm run dev
```

3. Open `http://localhost:3000` in your browser. The page should hot-reload as you edit files.

## Customising

* **Avatar** – replace `public/avatar.png` with a square head-shot of yourself (recommended ≈ 512×512).
* **Profile data** – edit `app/page.tsx` and adjust the `tiles` array plus headline, handle and bio.
* **Theme** – tweak the Tailwind colour palette inside `tailwind.config.js`.
